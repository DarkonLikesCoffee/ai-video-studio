# Frozen candidate record — BirdFlight

The brief, direction, storyboard, original source implementation, asset declaration, shot-to-code audit and render-readiness record are committed with this candidate.

The candidate is immutable once committed. The render request must be a separate commit changing only the repository-root render-request.json, with candidateSha equal to the exact remote branch head immediately before that request commit.

The frozen candidate SHA and render run ID will be recorded from actual workflow provenance; they are not guessed here.
